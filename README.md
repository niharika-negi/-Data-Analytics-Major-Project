# Smart City Analysis System | Data Analytics Major Project

## Project Overview

The Smart City Analysis System is a group-based data analytics
project designed to analyze urban data and generate meaningful
insights for better city management and decision-making.

The project integrates four major domains:

- Crime Analysis
- Traffic Analysis
- Energy Consumption Analysis
- Waste Management Analysis

Interactive dashboards were developed using Microsoft Excel,
Power BI and Python, along with MySQL database connectivity.

## Project Objectives

- Analyze urban data to identify patterns and trends.
- Understand crime distribution across different cities.
- Analyze traffic conditions and transportation patterns.
- Explore energy consumption and resource utilization.
- Analyze regional waste generation.
- Develop interactive and informative dashboards.
- Integrate multiple analytical domains into a single dashboard.
